How it works

Four simple hops.

The system stays deliberately legible. There is no black-box streaming service in the middle.

  1. 01

    Capture

    The desktop app grabs the display or window you choose.

    getDisplayMedia()
  2. 02

    Compress

    The Tauri host turns each frame into a JPEG payload.

    image/jpeg · 0.8
  3. 03

    Tunnel

    A small TCP protocol travels through USB to the phone.

    iproxy :12345
  4. 04

    Render

    Unity paints the latest frame onto a display in Cardboard VR.

    Texture2D.LoadImage

Build it yourself

Three moves.
Then headset.

NerdLens is a proof of concept, so setup is hands-on. Bring an iPhone, Google Cardboard, Unity 6, and a Mac with Xcode.

Read the complete setup guide ↗
Quick start 
# Clone
$ git clone https://github.com/ThatXliner/NerdLens.git

# Tunnel
$ iproxy 12345 12345

# Launch
$ cd NerdLens/desktop
$ bun install --frozen-lockfile
$ bun run tauri dev
